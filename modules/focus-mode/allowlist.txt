# Focus モードの許可リスト: 全ホスト共通のテンプレート部分。
#
# このリポジトリは公開されているので、業務に関わるもの (仕事で使うサービス・
# 顧客・社内のホスト名など) はここに書かない。それらはホストごとのローカル
# ファイル /etc/focus-mode/allowlist.txt (git 管理外) に書く:
#   focus allow <URL>                        追加
#   sudoedit /etc/focus-mode/allowlist.txt   編集・削除 (30 秒以内に反映)
#
# 書式 (ローカルファイルも同じ): 1 行 1 エントリ。# 以降はコメント。
#   example.com        example.com とそのサブドメインすべて
#   .example.com       example.com だけ (サブドメインは含まない)
#   example.com/docs   そのパス以下だけ
#   https://chromeenterprise.google/policies/url-patterns/
#
# 許可されるかどうかはページ遷移 (タブ / iframe) 単位で判定される。ページが
# 裏で読む CDN・フォント・API などは書かなくてよい。

# --- ブラウザ内部ページ・ローカル ---
chrome://*
chrome-untrusted://*          # 新しいタブページの部品
chrome-extension://*          # 1Password などの拡張のページ
file://*
localhost                     # *.localhost も含む
127.0.0.1
